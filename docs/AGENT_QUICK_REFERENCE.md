# VictorySync Agent Quick Reference

## Every contact

1. Review history.
2. Complete outreach.
3. Log activity.
4. Update disposition.
5. Update times contacted.
6. Confirm pipeline stage.
7. Schedule the next step.

## Import

Upload CSV/XLSX → map Email → map standard fields → add/named custom fields → preview → import once → verify Contacts.

## Good notes

Write what happened, what the contact said, and the exact next step with a date.

## Stop and ask an administrator when

- The wrong client appears.
- A required page is hidden or restricted.
- A bulk action includes unexpected records.
- Create, Import, Send, or Delete returns an error.

Include the full error, page, button, record/client, and time.
