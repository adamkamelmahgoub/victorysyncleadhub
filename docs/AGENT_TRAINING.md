# VictorySync Lead Generation Hub — Agent Training

## Training goal

After this training, an agent should be able to enter from the VictorySync dashboard, work the correct client account, manage contacts, record outreach, use dispositions and contact attempts, update the pipeline, schedule next steps, and report errors correctly.

## 1. Sign in and access

1. Open the Lead Generation Hub from the VictorySync dashboard.
2. You should be signed in automatically.
3. Confirm your name, role, and client context.
4. The sidebar only shows pages your administrator enabled.
5. If you see **Access restricted**, ask an administrator to review your Team & Members permissions.

Never share passwords, invite codes, session links, or client data.

## 2. Required daily workflow

1. Review new, assigned, and overdue contacts.
2. Open the contact record and review prior activity.
3. Complete the outreach.
4. Log the call, email, text, meeting, or other activity.
5. Update **Times Contacted**.
6. Select the correct disposition.
7. Add factual notes and the agreed next step.
8. Move the contact to the correct pipeline stage when its criteria are met.
9. Create a follow-up task.
10. End the day with accurate stages and no forgotten next actions.

## 3. Contacts

- Search by contact, email, or company.
- Use filters before selecting multiple records.
- Verify email and phone information before outreach.
- Keep status, disposition, source, company, title, notes, and custom fields accurate.
- Avoid duplicate contacts. Search before creating a new record.
- Use **Select all** carefully; it applies to the visible list.

## 4. Importing CSV/XLSX files

1. Open **Import Contacts**.
2. Upload a `.csv` or `.xlsx` file no larger than 10 MB.
3. Map the Email column. Email is required.
4. Map standard fields such as name, phone, company, title, source, status, disposition, and times contacted.
5. For any additional spreadsheet column, select **Add field**, enter the CRM field name, and choose its source column.
6. Review the preview carefully.
7. Import once.
8. Confirm the contacts and custom-field columns on the Contacts page.

If first or last name is blank, the CRM attempts to derive it from the email.

## 5. Dispositions and contact attempts

- A disposition records the outcome of the latest meaningful contact attempt.
- Use the team’s agreed disposition list.
- Do not create spelling variations of an existing disposition.
- Increase **Times Contacted** only after a real outreach attempt.
- Add a note when the outcome needs context.

## 6. Pipeline

- Select the correct pipeline for the client or sales process.
- A stage describes the current deal position.
- Move a contact only when the stage criteria are met.
- Do not use pipeline movement as a substitute for logging activity.
- Every active opportunity should have an owner and next step.

## 7. Client accounts and permissions

- Work only within the client account assigned to you.
- Administrators manage roles, client assignments, pages, and features through **Team & Members**.
- Report incorrect or excessive access immediately.
- Owners and administrators should review access whenever responsibilities change.

## 8. Data-quality rules

- Record facts, not assumptions.
- Do not invent contact information.
- Do not overwrite another agent’s notes.
- Keep dates, outcomes, and next actions specific.
- Never import the same file repeatedly.
- Never delete or bulk-edit records unless you have confirmed the scope.

## 9. Error reporting

Send the administrator:

- The full error message
- The page and button used
- The affected contact or client
- The approximate time
- Whether the action created any record before failing

Do not repeatedly click Create, Import, Send, or Delete after an error.

## Agent certification checklist

- [ ] Can enter through the VictorySync dashboard without a second login
- [ ] Can find and open a contact
- [ ] Can log an activity and note
- [ ] Can update disposition and times contacted
- [ ] Can create a follow-up task
- [ ] Can move a qualified contact through the pipeline
- [ ] Can import a file and map a custom field
- [ ] Understands client-account boundaries
- [ ] Knows how to report an error
