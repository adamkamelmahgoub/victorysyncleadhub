# Social workspace setup

The social CRM and workspace migrations are additive. Apply `supabase/migrations/20261022_social_workspace.sql`, `supabase/migrations/20261023_social_channel_expansion.sql`, and `supabase/migrations/20261024_threads_oauth.sql` in order in other environments. The social workspace is fixed to Victory Sync's internal organization (`cfbaf78a-3caa-4cb2-a367-d3b3eb161ba1`); there is no organization picker for campaigns, accounts, posts, or reports. The owner controls access under **Team > Social workspace access**. Clients and viewers cannot access the social workspace; grant internal teammates only the permissions they need.

## Existing server configuration

The app still needs its existing Supabase and worker settings: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` (or `SUPABASE_SERVICE_KEY`), `SUPABASE_ANON_KEY`, `DATABASE_URL`, and `OUTREACH_WORKER_TOKEN`. The existing Supabase Vault secrets `victorysync_leadgen_origin`, `victorysync_native_worker_token`, and Slack webhook must remain configured. `OPENROUTER_API_KEY` enables intent classification and AI drafts. The older `META_*`, `WHATSAPP_*`, and `TOKEN_ENCRYPTION_KEY` variables remain supported for previously provisioned accounts, but **new UI connections do not need social provider env vars**. App secrets, verify tokens, and account tokens are stored in Supabase Vault and are never returned to clients.

## Facebook Pages and Instagram Professional

1. At [Meta for Developers](https://developers.facebook.com/apps/), create a Business app. Add Facebook Login for Business, Messenger, Instagram, and Webhooks. Note the App ID and App Secret. Keep the app in development mode for app-role testing.
2. Change the Instagram account to Professional (Business or Creator) and link it to a Facebook Page you manage. [Meta's Instagram API documentation](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api) requires a linked Page for Facebook Login and excludes personal Instagram accounts.
3. In Victory Sync, open **Settings > Connected Accounts**. Enter the App ID, App Secret, and Graph API version. Save the app. Copy the displayed OAuth callback into **Facebook Login for Business > Settings > Valid OAuth Redirect URIs**.
4. Copy the displayed webhook callback into the Meta Webhooks product. Copy the one-time verify token immediately; the UI shows it only once. Subscribe messaging webhook events, including echoes where the Meta dashboard offers them. The endpoint verifies `X-Hub-Signature-256` before processing.
5. Request `pages_show_list`, `pages_manage_metadata`, `pages_read_engagement`, `pages_messaging`, `pages_manage_posts`, `instagram_basic`, `instagram_manage_messages`, and `instagram_content_publish`. App-role users can test role-linked accounts in development mode; broader use needs Meta App Review and Advanced Access as applicable.
6. Click **Connect with Facebook** in Victory Sync and authorize the Pages. The callback exchanges the short-lived Facebook user token for a long-lived user token, then discovers Page tokens and linked Instagram IDs through [Meta's Page token workflow](https://www.postman.com/meta/instagram/request/lpx8lul/get-access-tokens-of-pages-you-manage). It also subscribes each Page to messaging and echo webhooks. Confirm that both accounts appear in Settings. If a Page card shows a subscription error, fix the Webhooks product setup and click **Repair webhooks** on that card. Send a test inbound message and a manual app message to verify webhook and echo capture. Instagram messaging webhook fields still need to be enabled for the Instagram object in Meta's Webhooks dashboard.
7. Open **Social workspace** to draft or schedule Facebook Page text/image posts and Instagram Professional image posts or Reels. Media must have a public HTTPS URL. The five-minute Supabase worker publishes due posts; Instagram uses a media container and `media_publish` per [Meta's official publishing collection](https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api).

## Threads and other profiles

- For Threads API publishing, create a Meta app with the Threads use case. Under **Settings > Connected Accounts > Threads API**, enter the Threads App ID and App Secret, then copy the displayed OAuth callback into the Threads app's allowed redirect URIs. Enable and request the `threads_basic`, `threads_content_publish`, and `threads_manage_insights` scopes. Click **Connect Threads** to authorize the account. Victory Sync exchanges the code for a long-lived token, stores it in Supabase Vault, refreshes it when due, and can publish text, image, and video Threads posts and retrieve supported insights. Existing long-lived tokens can still be entered under the advanced section. [Meta's Threads API collection](https://www.postman.com/meta/threads/collection/dht3nzz/threads-api) documents the token exchange and publishing APIs.
- Add a manual profile for LinkedIn, X, TikTok, YouTube, Pinterest, Bluesky, Mastodon, Nextdoor, Yelp, or another network in **Connected Accounts**. A public profile URL and label suffice. You can schedule a post, open the profile, copy its text, confirm when you published it, and enter the platform's real stats. These accounts do not grant API access or automated publishing. Availability of publishing APIs depends on each platform's app approval and scopes.
- For manual posts, the worker moves due targets to the manual queue. Use **Mark published** after posting on the network, then **Update stats** when metrics are available. Do not confirm publication before it happens.

The [Messenger Send API](https://www.postman.com/meta/messenger-platform-api/folder/vilwbh4/send-api) limits ordinary API replies to the 24-hour customer messaging window. This CRM enforces the window. It does not automate cold sends from personal accounts.

## WhatsApp Business Cloud API

1. In Meta Business Manager, create or choose a WhatsApp Business Account and business phone number. Record the WABA ID and Phone Number ID.
2. In **Settings > Connected Accounts**, enter those IDs and a Cloud API token. The server verifies the phone through [Meta's official phone number endpoint](https://www.postman.com/meta/whatsapp-business-platform/request/86mq7mn/get-phone-numbers), stores the token in Vault, and subscribes the WABA webhook.
3. Use the Meta webhook callback and verify token from the UI. Test an inbound message and reply inside the rolling 24-hour support window. Sending outside that window requires approved templates and opt-in; cold WhatsApp is unavailable.

## Daily use and limits

- **DM queue** records human assisted follows, engagement, and sends. It applies per-account caps, warmup, suppression, and reply stopping rules.
- **Unified inbox** combines social, email, and MightyCall SMS replies. Incoming messages are matched to CRM records, classified for intent, and surfaced in an Unmatched view if no record matches. AI drafts are never auto-sent.
- **Social workspace** stores drafts, scheduled posts, publish outcomes, and per-post metrics. **Social reports** offers 7, 30, 90, and 365 day views, daily activity, channel and account breakdowns, campaign funnel, reply rate and latency, top posts, publishing counts, and CSV export. Provider reach and views appear only where the provider returns them or a teammate enters them; blank fields are not estimated. Conversation intent and campaign enrollment columns describe current state, so they can differ from historical event counts.
- **Team** lets the owner grant inbox view/reply, queue work, campaign management, social profile editing, account management, post creation/publishing, report viewing, and social MCP permission. Client accounts are excluded by database guard and server authorization.
- **MCP** offers the original social CRM tools plus social post listing/scheduling, a social report, owner team access tools, and forms/landing page management. Existing MCP authentication still uses `MCP_ALLOWED_EMAILS`; granting the `mcp_use` flag alone does not provide a team member an MCP credential. See [Forms and landing pages](docs/MARKETING_FORMS_PAGES.md) for the public routes and MCP connection checks.
- LinkedIn, TikTok, X, Threads, Yelp, Nextdoor, and Angi remain manual assisted for DMs. Native API publishing currently supports Facebook Page feed posts, Instagram Professional image posts and Reels, and Threads text/image/video. Stories, carousels, and unapproved platform APIs are not in the native publisher.

The previous server-side provisioning script remains available for legacy account recovery. Do not paste tokens into tickets, logs, or source control.

## Personal Instagram and LinkedIn through Unipile

Apply `supabase/migrations/20261025_rep_dm_tracking.sql` after the Threads migration. In **Settings > Connected Accounts > API connections**, the workspace owner enters the Unipile API key. Both the key and webhook signing secret are stored in Supabase Vault; no provider environment variable is required. Copy the displayed signed webhook URL into **Unipile Dashboard > Webhooks > Add endpoint**, subscribe to `message.new` and account status events, and paste the endpoint's signing secret back into Settings. Each teammate accepts the account-owner consent checkbox and connects their own Instagram or LinkedIn account using Unipile hosted authentication. The callback checks the returned account ID and provider before activating it. See [Unipile hosted auth](https://developer.unipile.com/v2.0/docs/authenticate-with-hosted-auth) and [webhook signing](https://developer.unipile.com/v2.0/docs/configure-a-webhook).

Only human initiated replies to a previously received message can use the Unipile API, and the CRM applies a 24-hour reply window, suppression, account ownership, and daily caps. Cold first touches, follows, likes, and connection requests remain manual. The webhook captures received messages and sent messages from another device; unknown senders remain in Unmatched until linked to a CRM record. A connected Unipile account requires both the hosted authorization and a signed webhook endpoint before the inbox will stay current. Test with one inbound message and one manually sent phone message after connecting.
